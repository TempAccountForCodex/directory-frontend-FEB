**Symptom:** writing a review and pressing submit sends you (or your visitor) to the login page instead of posting the review.

## This is usually expected

Submitting a review requires being **logged in**. If you write a review while signed out, you'll be asked to log in first and then sent back to the listing to finish posting. This keeps reviews accountable and helps prevent spam. See [reviews and replies](/docs/reviews-and-replies).

So if you weren't logged in: log in and submit again — the review will post.

## If you're already logged in and it still happens

This usually means your session has ended or your browser isn't keeping you signed in:

- **Log out and back in** to start a fresh session, then try again.
- **Allow cookies** for the site. If your browser blocks cookies (or you're in a strict private/incognito window), the site can't tell that you're logged in.
- **Try a different browser** to rule out a browser setting or extension.

## Still stuck?

If you're logged in, cookies are allowed, and it still redirects, contact support and mention which listing you were reviewing.
