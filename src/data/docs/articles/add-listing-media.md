Media makes a listing stand out. The listing editor has two media areas: the main listing image used in cards and previews, and limited inline media inside the rich description.

## Types of media

- **Listing image** — the main image used in the directory card preview.
- **Website image** — reuse the current website image when it already represents the business well.
- **Inline description media** — images or a video inserted into the detailed description.

## Uploading

1. Open the listing editor from the website dashboard.
2. Use **Upload Image** to choose a new main listing image, or **Use Website Image** to reuse the website image.
3. Use the rich description editor's image or video buttons to insert inline media where it belongs in the description.
4. Save the listing and confirm the preview looks correct.

## Image guidance

- Use widely supported image formats: JPEG, PNG, or WebP.
- Inline description media can include up to **2 images**, or **1 image and 1 video**.
- Videos should use a supported format such as MP4, WebM, or QuickTime.
- Keep file sizes reasonable so pages load fast. See [images and media](/docs/images-and-media) for details.

## If an upload fails

Large files, unsupported formats, or a backend connectivity issue are the usual causes. See [upload fails](/docs/upload-fails).
