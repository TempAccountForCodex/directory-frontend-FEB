A directory listing makes your business discoverable in the shared public directory. This guide gets your first listing live.

## 1. Start from a website

Listings belong to websites. From the dashboard, open the website you want to list and choose **Set Up Directory Listing**. A listing starts as a draft — it is yours and not yet public. See the full [listing lifecycle](/docs/directory-listings).

## 2. Fill in the required fields

A listing must be **complete** before it can be published. The editor shows a readiness score and blocks publishing until the listing reaches the required threshold. At minimum you typically need:

- Business name
- A detailed business description
- Category
- Contact details, such as email or phone
- Location details, such as city and country
- Tags that help visitors understand what you offer

The editor shows which fields are still missing. See [listing completeness requirements](/docs/listing-completeness) for the full list.

## 3. Add media

Choose the listing card image and, if useful, add limited inline media inside the description. See [add listing media](/docs/add-listing-media).

## 4. Publish

Once the listing is complete, publish it. It moves to the **published** state and becomes visible in the public directory.

## 5. Verify it shows

Open the public directory and confirm your listing appears. If it does not, see [why a listing may not show publicly](/docs/why-a-listing-may-not-show).
