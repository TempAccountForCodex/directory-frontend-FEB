Every directory listing moves through a defined lifecycle. Knowing which state a listing is in explains exactly why it is or is not visible to the public.

## The states

| State | Visible publicly? | Meaning |
| --- | --- | --- |
| **Not listed** | No | No listing exists yet for this business. |
| **Draft** | No | Created and being edited; never been published. |
| **Needs completion** | No | Started but missing required fields; cannot publish yet. |
| **Published** | Yes | Complete and live in the public directory. |
| **Archived** | No | Previously published, now intentionally hidden. |

## How a listing moves between states

- **Not listed → Draft** — you create the listing.
- **Draft → Needs completion** — you save with required fields still missing.
- **Needs completion → Published** — you fill every required field and publish. See [completeness requirements](/docs/listing-completeness).
- **Published → Archived** — you unpublish/archive it; it disappears from the directory but is kept.
- **Archived → Published** — you republish it; it returns to the directory.

## Why this matters

A listing is **only** public in the *published* state. If you can see a listing in your dashboard but the public cannot, it is almost always in one of the non-public states above.
