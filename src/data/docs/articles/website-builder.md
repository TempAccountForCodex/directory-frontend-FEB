The website editor is a visual, drag-and-drop builder. A page is made of stacked **sections** (also called blocks) that you add, arrange, and edit — no code required. You reach it from your website's **Pages** area by opening a page to edit.

## Adding sections

Open the **Block Library** (Add Block) and pick a section. Blocks are grouped into tabs so they're easy to find:

- **Core** — essentials like headers, footers, and hero banners.
- **Content** — text, images, galleries, FAQs, and rich layouts.
- **Dynamic** — sections that pull in live content, such as your directory listings.
- **Conversion** — calls to action, contact forms, and signup blocks.
- **Social Proof** — testimonials, reviews, and logos.
- **My Templates** — sections you've saved to reuse later.

You can drop a block **at the beginning**, **at the end**, or right after any existing section.

## Editing and arranging

- **Edit** a section by selecting it — change text, swap images, and adjust its style with the toolbar.
- **Reorder** sections by dragging them into place.
- **Show or hide per device** — each section can be set to appear on desktop, tablet, and/or mobile, so you can tailor the layout to screen size.
- **Preview** at any time, and switch between desktop, tablet, and mobile views to check how it looks.

## Saving, undo, and recovery

- Your work **autosaves** as you go — the save indicator shows **Saving / Saved / Unsaved**.
- Use **Save changes** to save immediately, and **Undo** to step back.
- If you leave with unsaved changes, you'll be offered the chance to recover them next time.

## Pages

A website can have multiple pages. Use **Add Page** to create one and your menu to link between them. Manage all pages from the website's **Pages** tab — see [manage your website](/docs/manage-your-website).

## Publishing

When you're happy, choose **Publish** to make your changes live. You can keep editing afterward; updates only appear publicly the next time you publish.
