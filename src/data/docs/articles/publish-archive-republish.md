Publishing controls whether a listing is visible in the public directory. These four actions move a listing between visible and hidden states.

## Publish

Makes a **complete** listing live. The listing moves to the *published* state and appears in the public directory. Publishing is blocked until the listing passes [completeness](/docs/listing-completeness).

## Unpublish / Archive

Takes a published listing out of the directory. The listing moves to the *archived* state. Your data is preserved — nothing is deleted — but the public can no longer see it. Use this when a business is temporarily closed or you are reworking the listing.

## Republish

Returns an archived listing to the directory. As long as the listing is still complete, republishing moves it back to *published* and it reappears publicly.

> Favorites are preserved across archive/republish. When a listing is republished, visitors who favorited it keep their favorite. See [favorites](/docs/favorites).

## Quick reference

| Action | From → To | Public result |
| --- | --- | --- |
| Publish | Draft/Needs completion → Published | Appears in directory |
| Unpublish / Archive | Published → Archived | Removed from directory |
| Republish | Archived → Published | Reappears in directory |
