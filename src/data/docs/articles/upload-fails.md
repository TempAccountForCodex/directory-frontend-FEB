**Symptom:** a photo or file upload fails, gets stuck, or never shows a thumbnail.

## Quick fixes

### 1. Check the file

- **Format** — use a supported type: JPEG, PNG, or WebP for images; MP4, WebM, or QuickTime for inline listing videos. See [images and media](/docs/images-and-media).
- **Size** — very large files may be over the limit. Resize the image smaller and try again.
- **The file itself** — open it on your device to make sure it isn't damaged.

### 2. Check your connection

A dropped or slow internet connection is a common cause. Make sure you're online, then retry the upload.

### 3. Try again

Uploads occasionally fail for a moment. Refresh the page and upload once more — most one-off failures clear up on a second try.

### 4. Sign in again

If you've been away for a while your session may have ended. Log out and back in, then upload again.

## Still failing?

If the same file keeps failing after the steps above, contact support and let us know the file type and roughly how large it is — that helps us pinpoint the cause quickly.
