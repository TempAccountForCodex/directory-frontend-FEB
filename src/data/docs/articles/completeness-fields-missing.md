**Symptom:** the editor says a required field is missing and blocks publishing, but you believe you filled it in.

## Common causes and fixes

### 1. The change was not saved

Edits live in a draft until saved. Save the listing and re-check. If autosave is in flight, wait for the "saved" confirmation before publishing.

### 2. Whitespace-only values

A field containing only spaces counts as empty. Re-type the value with real content.

### 3. The wrong field

Required and optional fields can look similar. The editor highlights the exact field that is missing — match the highlight, not the field you assume it means. See [listing completeness](/docs/listing-completeness) for the required set.

### 4. Media not finished uploading

If you added a listing image or inline description media and the upload did not complete, the saved listing may still contain the old value. Confirm the preview updates, then retry. See [add listing media](/docs/add-listing-media).

### 5. Refresh the editor

Sometimes the check lags behind a quick edit. Reload the page so the editor re-reads your saved listing, then check again.

## Still stuck?

If everything looks filled in and saved but the listing still won't publish, contact support with your listing name — we can check it from our side.
