A listing must be ready before it can be published. Completeness is the platform's guarantee that public listings have enough information to be useful.

## Typical required fields

The exact set may evolve, but a ready listing generally includes:

- **Business name**
- **Description** — a detailed, business-relevant description that meets the current word-count rule
- **Category** — so the listing is filed correctly in the directory
- **Contact details** — at least one of email or phone
- **Location details** — usually city and country
- **Tags** — short labels that describe what you offer

Optional-but-recommended fields such as full address, region, price level, listing image, and inline description media improve discoverability but may not block publishing.

## How completeness is enforced

When you save or attempt to publish, the listing is checked against the required set and the current readiness threshold, currently **60%**. If anything is missing, the listing enters or stays in the **needs completion** state and the editor shows which fields are outstanding.

## Confirming completeness

- The editor flags missing fields inline.
- The publish action is blocked until the listing is ready enough to publish.
- Once complete, publishing succeeds and the listing becomes public.

## If completeness seems wrong

If the editor says a field is missing but you believe you filled it, see [completeness says fields are missing](/docs/completeness-fields-missing).
